# SchoolOS · Mentor (модуль «План виховної роботи»)

> Дизайн повторює токени з `schoolosua.github.io` та `chronos/src/styles.css`:
> шрифти Clash Display + Inter + Space Grotesk, світла "скляна" тема,
> синьо-блакитний градієнт `--primary-neon → --accent`, золотий акцент
> `--gold` для пам'ятних дат, ті самі радіуси й тіні (`--radius-lg`,
> `--shadow-premium`, `--shadow-clay`).

Модуль показує державні свята та пам'ятні дати України у вигляді
календаря-довідника — основа для річного плану виховної роботи ЗДВР.

## Структура проєкту

```
schoolos-calendar/
├── index.html                          ← сторінка модуля (відкривати цей файл)
├── data/
│   ├── holidays-2026.json              ← державні свята (оновлюється автоматично)
│   ├── holidays-2027.json              ← державні свята (оновлюється автоматично)
│   ├── chl-2026.json                   ← пам'ятні літературні дати НБУ для дітей
│   ├── daytoday-2026.json              ← свята-події daytoday.ua (оновлюється автоматично)
│   ├── daytoday-2027.json              ← свята-події daytoday.ua (оновлюється автоматично)
│   ├── rada-2026.json                  ← офіційні свята ВРУ (оновлюється автоматично)
│   ├── rada-2027.json                  ← офіційні свята ВРУ (оновлюється автоматично)
│   └── updated.json                    ← дата останнього оновлення бази (пише write_meta.py)
├── vendor/
│   └── docx.umd.js                      ← docx 8.5.0 локально (Word-експорт кошика «Мій план»)
├── scripts/
│   ├── fetch_holidays.py               ← скрипт автооновлення (Nager.Date API)
│   ├── fetch_un_days.py                ← дні ООН (un.org + uk.wikipedia)
│   ├── fetch_daytoday.py               ← свята-події (daytoday.ua)
│   ├── fetch_rada.py                   ← офіційні свята (zakon.rada.gov.ua)
│   ├── fetch_chl.py                    ← літературні дати (chl.kiev.ua, НБУ для дітей)
│   └── write_meta.py                   ← записує data/updated.json (дата оновлення)
└── (workflow автооновлення живе в корені основного репозиторію
    у .github/workflows/update-events.yml — автозапуск 1 липня та 1 грудня)
```

## Як розгорнути (GitHub Pages)

Модуль живе в репозиторії основного сайту (`schoolosua.github.io`) у папці
`schoolos-calendar/` і публікується разом з ним за адресою:
`https://schoolosua.github.io/schoolos-calendar/`

## Як розгорнути (Vercel — альтернатива)

1. Зайди на vercel.com → **Add New → Project**
2. Обери репозиторій `schoolos-calendar`
3. Framework Preset: **Other** (це звичайний HTML, білд не потрібен)
4. Натисни **Deploy**

## Перший запуск автооновлення (не чекаючи до липня)

1. У репозиторії відкрий вкладку **Actions**
2. Обери зліва **Update Calendar Events**
3. Натисни **Run workflow → Run workflow**
4. Через ~30 секунд файли `data/holidays-2026.json` і `data/holidays-2027.json`
   заповняться реальними державними святами замість прикладу-заглушки

## Наступний крок: пам'ятні дати

Парсер пам'ятних дат уже підключено: скрипт `scripts/fetch_memorable.py`
збирає події з Історичного календаря УІНП (uinp.gov.ua, ~380 запитів,
кілька хвилин — це нормально). Кожна подія має `url` на сторінку
першоджерела на сайті УІНП. Він запускається тим самим workflow
`Update Calendar Events` разом зі святами і наповнює файли
`data/memorable-2026.json` / `data/memorable-2027.json`.

## Дні ООН

Скрипт `scripts/fetch_un_days.py` збирає міжнародні дні й тижні ООН:
дати — з офіційного переліку un.org (241 подія), українські назви — зі
статті uk.wikipedia.org «Міжнародні дні ООН» (зшивка за датами; для
назв, яких у вікі немає, переклади зашиті в `OVERRIDES`). Кожна подія
має `url` на сторінку обсервансу un.org. Результат —
`data/un-days-2026.json` / `data/un-days-2027.json` (тип `оон`).

## Пам'ятні літературні дати (НБУ для дітей)

Скрипт `scripts/fetch_chl.py` збирає «Пам'ятні літературні дати <рік> року»
з сайту Національної бібліотеки України для дітей (chl.kiev.ua): знаходить
видання за рік, обходить 12 сторінок місяців і парсить таблицю
(день + «N років від дня народження <особа>…»). Результат —
`data/chl-<рік>.json` (тип `памятна`; ~240 ювілеїв на рік).

Щоб не дублювати вже наявні записи, скрипт перед збереженням звіряється
з рештою файлів `data/` за той самий рік: точний збіг `(дата + назва)`
пропускається завжди, а ювілей, який на ту саму дату вже є в
`memorable-<рік>.json` (УІНП) про ту саму особу (збіг основи прізвища),
відсіюється окремо.

## Свята та події daytoday.ua

Скрипт `scripts/fetch_daytoday.py` збирає «свята-події» (всесвітні,
міжнародні, незвичайні дні) з daytoday.ua — 12 сторінок місяців
(`/<місяць>-svyata-ta-podii/`, списки розбиті на частини через `?_page=N`).
Рік визначається не з H1 сторінки (він часто відстає), а з заголовка
(`<title>`) події-першоджерела: «Всесвітній день страуса (2026)».
Релігійні свята відсікаються зіставленням із «Церковним календарем»
daytoday.ua за той самий день. Результат — `data/daytoday-2026.json`
(тип `день`; ~2900 подій; кожна має `url`-першоджерело і прапорці
`holovni-podii`, `plavaiucha-data`, `ne-propustit`).

УВАГА: daytoday.ua показує тільки поточний рік (плаваючі свята прив'язані
до конкретного року), тому файл існує лише для 2026. Коли сайт перейде на
2027 — `fetch_daytoday.py` згенерує `daytoday-2027.json`, і його треба
додати до `DAYTODAY_YEARS` в `index.html`.

Джерела, яких немає або вони змінили верстку, дають нуль подій — тоді
регулярні вирази у скрипті треба оновити під нову структуру сторінки
(це легко помітити за повідомленнями «Помилка: не знайдено рік» або
картками = 0).

Якщо зібралось дуже мало подій (менше ~50 за місяць) — сайт УІНП змінив
верстку, і регулярні вирази у `fetch_memorable.py` треба оновити під нову
структуру посилань.

## Офіційні свята Верховної Ради України

Скрипт `scripts/fetch_rada.py` збирає «Календар офіційних свят в Україні»
з zakon.rada.gov.ua — сторінка `laws/main/days<рік>/name` (список за
місяцями). Сайт захищений від DDoS, тому скрипт ходить із браузерним
`User-Agent`. Кожна подія має `url` на сторінку дня
(`zakon.rada.gov.ua/laws/main/day<N>`) і категорію за кольором легенди
сайту (поле `category`): `державне`, `свято`, `професійне`, `релігійне`,
`міжнародне`, `памятна`. Результат — `data/rada-2026.json` /
`data/rada-2027.json` (тип `офіційне`; ~165 подій на рік).

Оскільки частина свят дублюється в інших джерелах (Новий рік, Великдень,
День Соборності тощо), на сторінці працює дедуплікація-ЗЛИТТЯ
(`mergeDuplicates`): події на ту саму дату, що мають ≥60% спільних слів у
назві, зводяться в одну картку. При цьому **жодне джерело не втрачається** —
на картці показуються всі пігулки-джерела («УГКЦ», «ПЦУ», «офіційне (ВРУ)»,
«державне»…). Основною стає подія з вищим пріоритетом:
`офіційне` (ВРУ) → `державне` (Nager) → `релігійне` → `памятна` → `оон` →
`день` → `шкільна`.

## Релігійні свята (УГКЦ / ПЦУ)

Скрипт `scripts/fetch_church.py` збирає великі свята, пости та дні поминання
за новоюліанським календарем з двох офіційних джерел:
  - УГКЦ — «Церковний календар УГКЦ» (Патріарша літургійна комісія, ugcc.ua);
  - ПЦУ — «Календар і богослужбові вказівки» (pomisna.info).
Результат — `data/ugcc-2026.json` / `data/pcu-2026.json` (тип `релігійне`).
Обидва файли зберігаються окремо (навіть якщо свято є і в офіційному
календарі ВРУ); розв’язка дублікатів і показ пігулок-джерел відбуваються
на фронтенді під час злиття.

## Формат одного запису у JSON

```
{
  "date": "2026-08-24",
  "name": "День Незалежності України",
  "name_en": "Independence Day",
  "type": "державне",
  "source": "Nager.Date API"
}
```

Поле `type` може бути: `державне`, `памятна`, `оон`, `день` (свята-події),
`шкільна`, `офіційне` (календар Верховної Ради), `релігійне` (календарі
УГКЦ та ПЦУ).
Необов'язкове поле `age` — масив `["1-4","5-9","10-11"]`, якщо подія
стосується не всіх класів.
